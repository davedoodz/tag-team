    What this is

    Every hand-built HTML surface made in the last 31 days across 9 repositories — 263 of them, from 2026-08-14 to 2026-08-28 — placed in space by what it was for.

    The edges are not decoration. Five kinds, each toggleable on the left:

    • purpose — the group and subgroup a surface belongs to (310)
    • real page links — one surface actually links to another (401)
    • shared vocabulary — the same distinctive words in title and path (346)
    • repository — where the file lives (263)
    • working week — the week it first appeared (263)

    Drag to orbit, scroll to zoom, hover to light a neighbourhood, click to pin a node and fly to it, double-click a surface to open the real page. / searches, Esc resets.

    Built by npm run atlas; positions are settled once at build time so the view is the same every visit.
